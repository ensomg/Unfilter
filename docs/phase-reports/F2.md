# Faz 2 Raporu — Desync motoru

Kapsam: `DesyncAction` veri modelini gerçek paketlere çeviren uygulayıcı ve
bunun `uf-core` motoruna bağlanması. Önceki fazların `Strategy` arayüzü
arkasında boş bıraktığı parça.

## 1. Tamamlanan iş paketleri ve kullanılan model

| İş paketi | Model | Durum |
|---|---|---|
| IPv4/IPv6 + TCP başlık okuma/yazma (`net::TcpPacket`), 5'li tuple | Opus 4.8 | ✓ |
| Saf `plan()`: split / disorder / TLS record split / HTTP case mangle / fake / window / OOB | Opus 4.8 | ✓ |
| `DataStrategy`: `plan` + paket yeniden kurma (SEQ, uzunluk, TTL, checksum) | Opus 4.8 | ✓ |
| Engine aktif-strateji yolu (ilk veri segmenti yeniden yazılır, gerisi passthrough) | Opus 4.8 | ✓ |

## 3. Açık riskler ve sapmalar

- **Canlı doğrulama beklemede:** golden *pcap* testleri yerine saf `plan()`
  golden'ları ve motor-sınırı entegrasyon testi kullanıldı. Gerçek ağda
  (WinDivert + yönetici) bit-bit ve bypass testi F8/canlı koşuma bağlı; bu
  oturumda sürücü yok.
- **Otomatik TTL:** `TtlSpec::Auto` için gerçek DPI'a hop sayısı ölçümü prober
  (F5) + canlı taramaya ait; burada güvenli varsayılan `DEFAULT_AUTO_HOPS = 8`
  kullanılır.
- **QUIC sahte Initial bu TCP yolunda değil:** `FakeKind::QuicInitialFake`
  atlanır; QUIC bypass ayrı iş (F4 okuma tamam).
- **OOB yaklaşık:** URG bayrağı + urgent pointer kuruluyor; zapret'in tam OOB
  davranışı canlı ayarlanacak.
- Checksum'lar backend'e bırakılır (F-fix'te `WinDivertHelperCalcChecksums`);
  yalnızca `badsum` fooling kasıtlı bozar ve geçerli işaretlenir.

## 4. Sonraki fazın başlangıç koşulları

- Prober (F5) `Candidate.spec` → `DataStrategy` ile motora takılır; tarama
  yürütücüsü merdiveni dener, `ScoreBoard`'u doldurur (servis orchestrator'da
  bağlandı).
- Canlı WinDivert testi: her eylem için golden pcap + en az bir engelli siteye
  bypass.
