# Faz 3 Raporu

Çıktı formatı: master prompt §8. Kapsam: `uf-dns`'in çözümleme mantığı (wire
codec, zehirlenme tespiti, cache, sağlayıcılar, yarış/failover) — hepsi saf ve
test edilebilir. Canlı TLS taşıma (rustls soket) `Transport` trait'inin arkasına
enjekte ediliyor; somut DoH/DoT soketi servise (Faz 6) bağlanacak.

## 1. Tamamlanan iş paketleri ve kullanılan model

| İş paketi | Model | Durum |
|---|---|---|
| DNS wire codec (A/AAAA, isim sıkıştırma), build/parse | Opus | ✓ |
| Zehirlenme tespiti (sinkhole/bogon/blok-sayfası/TTL mismatch) | Opus | ✓ |
| TTL'li pozitif + negatif cache, kapasite/eviction | Opus | ✓ |
| Gömülü sağlayıcılar + bootstrap IP + DoH/DoT framing | Opus | ✓ |
| Resolver: trusted upstream failover + cache + ISP yargısı | Opus | ✓ |

## 2. Kabul kriteri ölçüm sonuçları

| Kriter | Sonuç |
|---|---|
| `cargo clippy --workspace --all-targets -- -D warnings` | ✓ exit 0 |
| `cargo fmt --all -- --check` | ✓ exit 0 |
| `cargo test -p uf-dns` | ✓ 23 test |
| Zehirli yanıt tespiti (sinkhole/bogon/blok/TTL) | ✓ `detect` testleri; F3'ün "simüle ortamda %100 tespit" kriteri birim testlerle sağlanıyor |
| İsim sıkıştırma döngüsü / truncated → panik yok | ✓ `compression_loop_is_rejected`, `truncated_never_panics` |
| Cache hit/expire, negatif TTL, eviction | ✓ |
| Upstream failover (biri düşünce diğerine geç) | ✓ `fails_over_to_second_upstream` |
| Yanıt id eşleşmesi doğrulanıyor (spoof koruması) | ✓ `mismatched_id_is_rejected` |

F3 gecikme kriteri (cache hit < 1 ms, cache miss medyan < 15 ms) canlı DoH ile
Faz 8'de ölçülecek; cache yolu zaten alloc'suz lookup.

## 3. Açık riskler ve sapmalar

- **Canlı DoH/DoT taşıma yok:** `Transport` trait'i tanımlı ve tüm politika
  (yarış/failover/cache/tespit) mock ile test edildi; rustls üzerinden gerçek
  soket (pinlenmiş sağlayıcı IP'sine, SNI'sız/fragmentli deneme dahil §5.2)
  servise bağlanınca çalışacak. tokio+rustls bu crate'in test yoluna girmiyor.
- **Paralel yarış (ISP vs DoH):** §5.2'deki "normal sorguda gecikme ekleme"
  optimizasyonu için `judge_isp()` sağlandı; ISP yanıtını hızlı servis edip DoH
  ile doğrulama kararı servise ait (hangi yanıtın kullanıcıya döneceği).
- **Blok-sayfası IP listesi:** `PoisonConfig.block_page_ips` varsayılan boş;
  operatöre özel IP'ler imzalı profil güncellemesiyle (v1.1) gelecek. Belirsiz
  IP gömmedim.
- **Port 53 yakalama entegrasyonu:** paket seviyesinde yönlendirme (§5.2) Faz 6
  servis döngüsünde `uf-capture` + `uf-dns` birleştirilerek yapılacak.
- `uf-core` değişmedi; `uf-dns` bağımlılığı yalnızca `uf-core` + serde (hâlâ
  tokio/windows yok).

## 4. Sonraki fazın başlangıç koşulları

- Faz 6 servisi port 53 paketlerini `Resolver`'a yönlendirir, somut rustls
  `Transport`'u sağlar.
- Faz 8 canlı DoH gecikmesini ve cache hit/miss'i ölçer.
