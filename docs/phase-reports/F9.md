# Faz 9 Raporu

Çıktı formatı: master prompt §8. Kapsam: paketleme (Inno Setup), temiz-kaldırma
doğrulaması, Authenticode imzalama betiği ve kullanıcı dokümantasyonu (§5.9, §9).
Bu makinede gerçek MSI/kurucu derlenemez ve imzalanamaz (sertifika, sürücü,
yönetici yok); bu yüzden çalıştırılabilir, doğru betikler + yapılandırma üretildi
ve elle adımlar belgelendi.

## 1. Tamamlanan iş paketleri ve kullanılan model

| İş paketi | Model | Durum |
|---|---|---|
| Inno Setup kurulum betiği (servis + recovery + tray + duvar + temiz kaldırma) | Opus | ✓ |
| WiX/MSI alternatifinin belgelenmesi | Opus | ✓ |
| `scripts/verify-clean-uninstall.ps1` (iz taraması, non-zero çıkış) | Opus | ✓ |
| `scripts/sign.ps1` (signtool sarmalayıcı, parametreli, sırsız) | Opus | ✓ |
| `config/default.toml` (sıfır-yapılandırma profili) | Opus | ✓ |
| `README.md`, `docs/user-guide.md`, `docs/faq.md`, `CHANGELOG.md` | Opus | ✓ |
| AV/sürücü yanlış-pozitif + SmartScreen + yeniden-üretilebilir derleme notları | Opus | ✓ |
| Lisans tutarsızlığının işaretlenmesi + öneri | Opus | ✓ |

## 2. Kabul kriteri ölçüm sonuçları

| Kriter | Sonuç |
|---|---|
| `cargo fmt --all -- --check` | ✓ exit 0 (kaynak değişmedi) |
| `cargo build --workspace` | ✓ (kaynak değişmedi; yalnızca installer/docs/config/scripts eklendi) |
| Kurucu dosya düzeni (3 exe + WinDivert yanında + config) | ✓ `installer/unfilter.iss` [Files] |
| Servis kaydı + otomatik başlangıç | ✓ `sc create ... start= auto` |
| Recovery politikası (§6.4: 3× 5 sn, 1 gün reset) | ✓ `sc failure ... reset= 86400 actions= restart/5000 ×3` |
| Tray oturum açılışında | ✓ HKLM Run `Unfilter Tray` (uninsdeletevalue) |
| Temiz kaldırma: servis + WinDivert sürücü + duvar + kayıt + dosya + ProgramData | ✓ [UninstallRun]/[Registry]/[UninstallDelete] |
| Kaldırma doğrulaması betiği non-zero döner | ✓ `verify-clean-uninstall.ps1` iz bulursa exit 1 |
| İmzalama: 3 exe + kurucu, zaman damgalı, sır gömülü değil | ✓ `sign.ps1` (/tr + /td sha256; parola env/secure-prompt) |
| PowerShell 5.1 uyumu | ✓ (ternary/`??` yok; `${env:...}` kullanımı) |
| Boyut ≤ 8 MB kısıtı | izlendi (§3); kurucu ikilileri sıkıştırır, `check-size.ps1` ham ikilileri ölçer |

> Not: kurucunun kendisi (`iscc`), imzalama (`signtool` + sertifika) ve canlı
> kur/kaldır-doğrula döngüsü bu ortamda çalıştırılamadı (araç/sertifika/yönetici
> yok). Betikler Windows + Inno Setup 6 + Windows SDK olan bir makinede
> çalışacak şekilde yazıldı; CI'a bir "build installer + verify" adımı §4'te
> önerildi.

## 3. Açık riskler ve sapmalar

- **🔴 Lisans tutarsızlığı (çözüm bekliyor — kendim değiştirmedim):** depo kökü
  `LICENSE` **MIT**, ama workspace `Cargo.toml` `license = "GPL-3.0-or-later"`
  diyor. ADR 002 WinDivert (LGPLv3/GPLv2) uyumu için GPL-3.0-or-later'ı
  gerekçelendiriyor. Bunlar çelişir ve kullanıcıya ne dağıtıldığı belirsiz
  kalır.
  - **Teknik durum:** WinDivert **dinamik** bağlanır (ADR 002, `LoadLibraryExW`)
    ve değiştirilmemiş imzalı ikili olarak ayrı dağıtılır. LGPLv3'ün dinamik
    bağlama şartı, Unfilter'ın kendi kaynağının lisansını GPL'e zorlamaz; MIT de
    LGPL ile uyumludur. Yani teknik olarak MIT mümkündür.
  - **Önerim (sahibinin kararı):** tek bir lisansa karar verilsin.
    - **(A) MIT'te kal (önerilen):** `Cargo.toml`'daki `license`'ı
      `"MIT"` yap; ADR 002'nin lisans cümlesini "Unfilter MIT; WinDivert
      dinamik bağlı, ayrı LGPLv3/GPLv2 ikili, uyumlu" olacak şekilde düzelt.
      En az sürtünme; MIT zaten kökte duruyor.
    - **(B) GPL-3.0-or-later'a geç:** `LICENSE`'ı GPL-3.0 metniyle değiştir;
      kök lisansı `Cargo.toml` ile hizala. Daha katı copyleft isteniyorsa.
  - README ve F9 bu çelişkiyi açıkça işaretliyor; `Cargo.toml`/`LICENSE`/ADR 002
    üçlüsü aynı kararla güncellenene kadar tutarsızlık sürer. **Bu fazda kaynak
    değiştirmedim** (diğer fazlar paralel çalışıyor; görev talimatı crate
    kaynağına dokunmamamı istedi).
- **Servis giriş noktası henüz yok:** `uf-service.exe` şu an bir saplama
  (`fn main() {}`); SCM dispatcher Faz 6'da gelir. Kurucu `sc create` ile servisi
  kaydeder ama `sc start` saplamada anlamlı çalışmaz. [Run] adımları hatada
  ölümcül değildir (Inno dış program çıkış kodlarını hata saymaz), bu yüzden
  kurulum yine tamamlanır. Canlı kur-başlat-kaldır döngüsü Faz 6 + imzalı ikili
  sonrası doğrulanacak.
- **WinDivert sürücü servis adı varsayımı:** kaldırıcı `WinDivert` adlı sürücü
  servisini siler (WinDivert 2.2 varsayılanı). Faz 6 `WinDivertOpen`'a özel bir
  cihaz/servis adı verirse `installer/unfilter.iss` ve `verify-clean-uninstall.ps1`
  içindeki `DriverService` değeri güncellenmeli.
- **Güvenlik duvarı kuralı:** giden trafik Windows'ta zaten varsayılan izinli
  olduğundan kural çoğu kurulumda gereksizdir; yine de kısıtlı/kurumsal
  profiller ve "temiz kaldırma yüzeyinin tam gösterimi" için eklendi ve
  kaldırmada siliniyor. İstenmezse [Run]/[UninstallRun]'daki `netsh` adımları
  çıkarılabilir.
- **Boyut:** nihai dağıtım boyutu release ikilileri + WinDivert ile ölçülür
  (`check-size.ps1`); kurucu bunları LZMA2 ile sıkıştırdığından `.exe` daha
  küçüktür. 8 MB kısıtı ham ikililer üzerinden izlenmeli (slint/rustls/tokio
  yükü Faz 6'da gelir).
- **AppId GUID:** `unfilter.iss` içinde sabit bir AppId var; yayından önce bir
  kez üretilip kalıcı tutulmalı (yükseltme/kaldırma kimliği buna bağlı).

## 4. Sonraki fazın başlangıç koşulları

- **Lisans kararı** (A veya B) uygulanıp `Cargo.toml` + `LICENSE` + ADR 002
  hizalanmalı. Bu, yayın öncesi zorunlu bir karardır.
- Faz 6 servis SCM dispatcher'ını yazınca: imzalı release ikilisiyle gerçek
  bir makinede `iscc` → kur → `sc query`/durum → kaldır →
  `verify-clean-uninstall.ps1` döngüsü koşulup temiz kaldırma kanıtlanmalı.
- CI'a isteğe bağlı bir "installer" işi: `iscc installer\unfilter.iss` çalıştır,
  üretilen `.exe`'yi artefakt olarak yükle (imzalama sır gerektirir, salt
  release/tag'de).
- İmzalama sertifikası tedarik edilince `sign.ps1` CI'da bir güvenli imzalama
  adımında (thumbprint + HSM/token) kullanılmalı; SmartScreen itibarı için her
  sürüm aynı sertifikayla imzalanmalı.
