# ADR 005 — IPC: ACL'li named pipe üzerinde sürümlü JSON-RPC

**Durum:** Kabul (Faz 0)

**Karar:**
- Taşıma: `\\.\pipe\unfilter`, mesaj modu, `PIPE_REJECT_REMOTE_CLIENTS`. DACL: SYSTEM tam, etkileşimli oturum kullanıcısı okuma/yazma, diğer herkes yok.
- Çerçeve: satır sonuyla ayrılmış UTF-8 JSON (`\n`), mesaj başına üst sınır 64 KiB.
- Şema: `uf-ipc` crate'inde `ClientMessage { id, request }`, `ServerMessage::{Response, Event}`. İlk mesaj her zaman `Hello { protocol: PROTOCOL_VERSION }`; uyuşmazlıkta servis `Error::VersionMismatch` döner ve bağlantıyı kapatır.
- Servis olayları (durum değişimi, log satırı) push ile gönderilir; UI polling yapmaz (boşta CPU ≈ 0).

**Gerekçe:** Tam JSON-RPC 2.0 kütüphanesi gereksiz; tipler zaten iki tarafta da Rust. JSON, hata ayıklamada okunabilir ve `serde_json` zaten bağımlılık.

**Güvenlik:** Servis tüm istekleri yetkisiz girdi olarak doğrular. Ayrıntılı ACL ve yetki ayrımı incelemesi Faz 6'da (Opus).
